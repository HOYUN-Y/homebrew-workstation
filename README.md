# Workstation Agent for Mac

Workstation의 로컬 연결·스킬 실행용 Mac 앱입니다. 0.11.0은 다크 네이비 일반 창의 연결 / 스킬 / 실행·승인 세 탭으로 구성됩니다. 기존 업무·대화 작성·지식 그래프·원천 분석 화면은 로컬 앱에서 비활성화했으며 웹 기능과 기존 연결 자료는 유지합니다. Dock과 메뉴바에서 같은 창을 열 수 있습니다.

## 설치

Apple Silicon(M 시리즈), macOS 15 이상, Homebrew가 필요합니다. 사용할 Claude Code 또는 Codex CLI를 별도로 설치하고 로그인해주세요. Codex는 0.162.0 이상이 필요합니다.

```sh
brew tap HOYUN-Y/workstation
brew install --cask hoyun-y/workstation/workstation-agent
open -a "Workstation Agent"
```

[ZIP 다운로드](https://github.com/HOYUN-Y/homebrew-workstation/releases/latest)도 제공합니다. 수동 설치에는 `brew install uv`가 필요합니다. Python 3.14와 잠긴 실행기 의존성은 앱에서 ‘실행기 준비’를 누를 때 준비합니다.

Apple 유료 인증서와 공증 없이 ad-hoc 서명했습니다. 최초 실행이 차단되면 신뢰하는 다운로드인지 확인한 뒤 macOS ‘시스템 설정 → 개인정보 보호 및 보안’에서 직접 허용해주세요. [Apple 안내](https://support.apple.com/en-us/102445)

## 처음 연결하기

1. 앱을 열고 대시보드 서버 주소를 확인합니다.
2. ‘브라우저에서 로그인’으로 대시보드에 로그인하고 앱 연결에 동의합니다.
3. ‘실행기 준비’를 누릅니다. 사용할 엔진의 로그인 상태를 확인합니다.
4. ‘이 Mac을 대시보드에 연결’을 누릅니다.
5. 프로젝트를 선택하고 신뢰하는 개별 폴더를 등록합니다. 홈 폴더 전체와 실행기 내부 상태 폴더(`~/.local/share/workstation-agent`)는 등록하지 않습니다.
6. ‘자동 시작 설치·시작’을 누릅니다. 이는 실행 서비스를 자동 시작하며 메뉴바 앱의 로그인 시 실행 설정과는 별개입니다.

웹에서 올린 스킬은 앱에서 버전과 폴더를 선택하고 ‘선택 버전 준비’를 진행한 뒤 준비 완료 상태에서 실행합니다. ZIP은 해시·안전성 검사 후 실행기 전용 캐시에 준비됩니다. 기존 사용자·프로젝트 스킬을 덮어쓰지 않습니다. 파일 쓰기 등의 도구 요청은 앱/웹에서 내용을 확인한 후 승인하거나 거부합니다.

대시보드 로그인은 Keychain에, 기기 연결과 폴더 정보는 로컬 실행기 상태 폴더에 저장됩니다. 앱 로그아웃은 실행 서비스를 정지하거나 기기 연결을 해제하지 않습니다. 기기 연결 해제와 스킬 삭제·보관은 웹에서 처리합니다.

## 업데이트

서버나 웹만 변경되면 Mac 앱을 다시 설치할 필요가 없습니다. 로컬 실행기 변경이 있는 릴리스는 다음 순서로 적용합니다.

1. 앱에서 ‘신규 접수 일시 정지’를 누르고 진행 중 작업을 완료하거나 취소합니다.
2. ‘서비스 정지’를 누릅니다.
3. 앱을 닫고 터미널에서 업데이트합니다.

```sh
brew update
brew upgrade --cask hoyun-y/workstation/workstation-agent
```

4. 앱을 열고 ‘실행기 설치본 업데이트’를 누릅니다.
5. ‘자동 시작 설치·시작’ 후 연결·폴더 상태를 확인합니다.
6. 필요할 때만 ‘신규 접수 재개’를 누릅니다.

진행 중인 서비스가 있으면 실행기 설치본 교체는 중단됩니다. 연결·등록 폴더·이전 실행기 릴리스는 보존됩니다.

## 제거

신규 접수를 일시 정지하고 진행 중 작업을 완료/취소한 뒤 제거합니다.

```sh
brew uninstall --cask workstation-agent
```

메뉴바 앱과 실행 서비스는 종료하지만 기기 연결·폴더·로그·Keychain은 보존합니다. 필요하면 제거 전에 웹에서 기기를 연결 해제합니다.

## 검증 범위

첫 공개 릴리스의 확인 결과는 해당 Release 노트에 기록합니다. 다른 Mac과 macOS 15 실기 검증, 과거 공개 버전에서의 업그레이드는 별도입니다. 공식 homebrew-cask 등록이 아닌 이 저장소의 자체 tap으로 배포합니다.

## 0.10.4 참고

지식 조회·편집·수동 변경 분석은 앱에서 해당 권한을 별도로 연결합니다. 원천 폴더는 Mac마다 연결하며 자동 감시는 포함하지 않습니다. Swift·패키지·서명·ZIP 해시를 검증했습니다. 다른 Mac의 0.2.0 업그레이드와 장시간 성능 측정은 미검증입니다.

## 0.10.5 업데이트

세컨브레인과 대시보드 목록을 로컬 캐시에서 먼저 표시하고 필요한 자료를 갱신합니다. 코어/브레인 중앙 정렬, 창 크기 프리셋, 반투명 배경을 포함합니다. 기존 연결은 유지되며 키체인 허용 요청이 나올 수 있습니다. 실행 중 작업을 완료한 후 업데이트하고 앱의 실행기 준비로 포함된 실행기를 적용하세요. 자동 원천 감시는 포함하지 않습니다.

## 0.10.6 업데이트

GPU를 비동기로 준비하고 전환 화면을 재사용합니다. 첫 표시 후 입자 전환을 시작하며 프레임 지연으로 중간 과정이 생략되지 않도록 했습니다. 입자 수·선명도는 유지합니다. 합성 자동 검사와 패키지·원격 해시 검증을 통과했으며 실제 다른 Mac 설치·체감 검증은 후속입니다. 서버/API 변경은 없습니다.
